Because nums is sorted, any path between two nodes can only be broken when the difference between two consecutive values is greater than maxDiff, since no edge can bridge such a gap. Therefore, we scan the array from left to right and assign the same component ID to consecutive elements whose difference is at most maxDiff; otherwise, we start a new component. After preprocessing, each query is answered in constant time by simply checking whether the two queried nodes have the same component ID. This preprocessing takes O(n) time, answering all queries takes O(q) time, and the extra space used is O(n).
