The solution converts the integer n into a string so its digits can be processed from left to right. It then scans each digit, ignoring every 0. For each non-zero digit, it appends the digit to a new number x using x = x * 10 + digit, which shifts the existing digits one place to the left before adding the new digit, and at the same time adds the digit to sum. After all digits have been processed, x contains the number formed by all the non-zero digits in their original order, while sum contains the total of those digits. Finally, the algorithm returns x * sum, which is the required answer.
